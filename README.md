# حكاية الزمالة — النسخة التفاعلية

تجربة موشن تفاعلية (1080×1920) تُرسم مباشرة في المتصفح مع النشيد، وتنتهي بزر «ابدأ زمالتك» يفتح نموذج التسجيل:
https://forms.gle/C2QD3Gp8VG8fgNnAA

## تغيير رابط زر التسجيل
افتح index.html وعدّل السطر:
`window.CTA_URL = "https://forms.gle/C2QD3Gp8VG8fgNnAA";`
ضع الرابط الجديد بين علامتي التنصيص، ثم احفظ وارفع الملف.

## الرفع على GitHub Pages
1. ارفع محتويات هذا المجلد كما هي (index.html في جذر المستودع، ومعه المجلدات js و fonts و audio).
2. من Settings ← Pages اختر الفرع main والمجلد / (root).
3. عند ربط نطاق خاص، أضفه من نفس الصفحة (Custom domain).

كل المسارات نسبية، فالصفحة تعمل على أي نطاق دون تعديل.
